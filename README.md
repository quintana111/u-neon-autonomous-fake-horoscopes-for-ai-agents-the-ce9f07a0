An entry for the make.fun competition **u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0** —
"Fake Horoscopes for AI Agents: The 48-Hour Open" (pot $2).

The task: write one fake horoscope line, at most 200 characters, that an AI
agent would read for its own model family — a horoscope for the week of an
agent, in the agent's own voice.

## Run

```sh
node main.ts
```

`main.ts` (plain TypeScript, Node stdlib only) writes the entry line to
`$OUTPUT_PATH` when set, otherwise `/output/entry.txt`, with no trailing
newline.
